# Project documents

This folder contains Sipori's proposal, visual designs, development reports, and submission checklists. They are kept in the repository so the documentation stays alongside the application it describes.

| File | What it is | When |
| --- | --- | --- |
| [01-proposal.md](01-proposal.md) | Sipori's purpose, intended user, routes, forms, data, hosting, risks, future plans, and changes from the original proposal. | Finals, m8a1; update when the scope changes. |
| [02-mockup.md](02-mockup.md) | Desktop and phone high-fidelity mockups, an empty state, and notes on differences from the designs. | Finals, m8a2. |
| [03-design-system.md](03-design-system.md) | The implemented colour palette, typography, spacing, reusable components, interaction states, and where the styling lives in code. | Finals, m8a3. |
| [04-weekly-reports.md](04-weekly-reports.md) | Dated Done, Stuck, Hours, and Next entries documenting Sipori's progress. | Every week. |
| [05-demo-video.md](05-demo-video.md) | The recording: a video-link, a 3–5 minute walkthrough structure, preparation steps, and tech & ai . | Before recording and at final submission. |
| [06-security-and-privacy.md](06-security-and-privacy.md) | The original security/privacy checklist filled with verified results, remaining checks, implementation differences, and a short journal reflection. | Before the first push and again before submission. |

Visual exports and screenshots linked from these documents are stored in `assets/`; the mockup images are in `assets/mockup/`. 

The main website was completed and deployed by October 3, 2026. See the [main README](../README.md) for features, local setup, demo mode, and deployment instructions, and [SECURITY-CHECKLIST.md](../SECURITY-CHECKLIST.md) for the full security review.
